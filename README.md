# StyleAI 👔✨

AI Outfit Recommendation System

## Overview

StyleAI is a smart fashion recommendation system that suggests outfits based on:

* Skin Tone Detection
* Weather Conditions
* Occasion Selection
* Personal Style Preferences

The system uses Computer Vision, Weather APIs, Flask, and MySQL to generate personalized outfit recommendations.

## Features

✅ Skin Tone Detection from Uploaded Image

✅ Weather-Based Outfit Suggestions

✅ Occasion-Based Recommendations

* College
* Office
* Interview
* Party

✅ Pinterest-Style Outfit Gallery

✅ Responsive User Interface

✅ MySQL Database Integration
