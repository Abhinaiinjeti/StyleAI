# Database Setup

1. Create MySQL database:
   CREATE DATABASE outfit_recommender;

2. Run schema.sql

3. Run sample_data.sql

4. Update MySQL credentials in app.py

5. Start Flask application:
   python app.py
   

# Database Files

schema.sql
- Creates all required tables.

sample_data.sql
- Inserts sample outfit recommendation data.

Import order:
1. schema.sql
2. sample_data.sql
